First, run the development server:

```bash

# or
yarn dev

pnpm dev

```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Ambiente

Copie `.env.example` para `.env.local` e preencha. A porta é 3000, a mesma de
`.claude/launch.json`.

**`NEXTAUTH_URL` e `AUTH_URL` não devem ser definidas em nenhum ambiente.** O
next-auth reescreve a origem de toda requisição com esse valor, e o app passa a
redirecionar sempre para ela — a porta errada em desenvolvimento, o endereço de
outro cliente quando cada tenant tem seu subdomínio. `auth.config.ts` usa
`trustHost: true`, então a origem vem do host da requisição. `APP_URL` fica como
reserva e como origem do webhook registrado na YCloud, que precisa ser estável.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
